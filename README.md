🚀 Multi-App Python Intelligence Suite
This repository contains two independent Python + Streamlit projects combined into a single codebase:
Threat Intelligence Agent – A cybersecurity-focused dashboard that processes and analyzes threat intelligence data.
Intelligent BMI Calculator – A health-focused BMI calculator that provides personalized nutrition and food suggestions.
Both applications are built with Python, Pandas, and Streamlit, making them lightweight, interactive, and easy to run locally.

🧠 Project 1: Threat Intelligence Agent
The Threat Intelligence Agent is a cybersecurity analytics dashboard created with Streamlit and Pandas.
Features
Analyze and process threat intelligence datasets
Data filtering and visualization
Interactive dashboard UI using Streamlit
CSV/data ingestion support
Threat pattern exploration
Cybersecurity intelligence insights
Tech Stack
Python
Pandas
Streamlit
Data analysis libraries
